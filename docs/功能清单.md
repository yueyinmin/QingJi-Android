## 五、设置项

界面上是 **7 分组 27 项**，底层共 **68 个 DataStore 键**（`SettingsStore.kt`）。

| 分组 | 项 |

| 账号与安全 | 个人资料、隐私与安全 |

| 设备与数据 | AI 服务配置、数据导入与导出、缓存管理 |

**一级页面（4）**：`home` 首页、`progress` 进展、`diary` 日记、`mine` 我的。中间「＋」不是 Tab，是底部弹层 `AddRecordSheet`（对应 `add_record` 路由常量，不算全屏页面）。四个 Tab 都支持左右滑动切换。
