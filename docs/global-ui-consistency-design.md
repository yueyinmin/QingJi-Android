# 轻记全局 UI 视觉统一改造 — 设计规范与实施记录

**分支：** `feature/global-ui-consistency`（从 main `d19203b` 创建）
**基准：** 以 v1.0.8 设置页的极简风格为全局视觉基准，统一首页、进展页、我的页的设计语言。
**原则：** 统一的是视觉语言，不是把所有页面做成同一个模板——首页突出营养数据，进展页突出身体变化，我的页突出个人信息。

## 一、全局设计规范（本分支落地值）

### 颜色（落地在 `theme/Color.kt` + `theme/AccentThemes.kt`）

| 项 | 规范值 | 原值 | 落点 |
|---|---|---|---|
| 页面背景 | `#F3F3F6` | `#F4F5F6` | `Light.Page` |
| 卡片背景 | `#FFFFFF` | 不变 | — |
| 主色（松绿主题） | `#299D76` | `#1F8A70` | `AccentThemes.green.lightMain` |
| 浅绿 | `#EAF7F1` | `#E8F5EF` | `AccentThemes.green.lightSoft` |
| 主色深一档 | `#1F7E62` | `#16795F` | `AccentThemes.green.lightDark` |
| 主文字 | `#263B33` | `#1A1A1A` | `Light.Text` |
| 辅助文字 | `#9AA8A1` | `#8A8F98` | `Light.TextSub` |
| 分割线 | `#EEF0F0` | `#EEF0F2` | `Light.Divider` |

配套同步（避免新旧绿混用）：`macroCarb`（松绿主题）、`MultiColor.Lunch`、`MultiColor.QuickWeight` 同步 `#1F8A70 → #299D76`。深色模式色值不动。语义多彩色（喝水蓝/断食橙等）保持不变——主题管基调，语义色管功能识别，两条线互不打架。

### 卡片 / 字体 / 图标

- 卡片圆角：默认 16dp（现有 `Dimens.ItemCorner`），白色背景，阴影弱化。
- 卡片内边距 14–16dp，卡片间距 12dp（现有 `Dimens.Gap`）。
- 页面标题 24–28sp Bold；模块标题 16–18sp Semibold；普通文字 14–15sp；辅助文字仅保留必要信息。
- 图标：线性图标 + 低饱和浅色圆角容器（设置页已是此规范，其余页面沿用现有语义图标）。

### 文字原则

1. 删除不必要的灰色副标题与重复解释。
2. 列表行只留图标、名称、必要的当前值或箭头。
3. 数据页允许保留必要的单位、目标值和空状态提示，但禁止长篇说明。

## 二、逐页改造清单

### 进展页
- 身体数据卡空状态：「还没有体重记录，点底部「+」→ 记体重，就能看到曲线」→「还没有体重记录」。
- 体重走势空状态两行说明 → 一句「这个时间范围还没有体重记录」。
- BMI 与 BMI 分级已并列、时间筛选已是胶囊、图表已是柔和绿色——保留。

### 我的页
- 删除使用情况卡底部灰色说明「这里的数字就是你实际使用轻记的记录…」（按本轮任务书口径；注：v1.0.7 时期曾按旧口径保留过，本轮以新指令为准）。
- 使用情况已是两列紧凑统计、数据/成就已是设置页式分组列表——保留。

### 首页
- 悬浮快捷按钮：52dp → 44dp，图标 24dp → 20dp，垂直间距 10dp → 8dp；仍为四色语义，不遮挡底部导航。
- AI 分析按钮已是浅绿胶囊——保留。
- 热量/营养/水杯主卡结构保留（水杯在右侧独立列，未压缩营养区）。

### 底部导航
- 白色背景 + 选中浅绿胶囊已是现状——保留。

## 三、实施约束

- 只动主题常量与纯展示文案/尺寸，**不改业务逻辑、导航、数据库、Room Entity、Migration**。
- 每个页面单独提交、单独截图验证。
- 不合并 main、不发 Release。
