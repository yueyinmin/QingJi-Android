## 1. 结论

长期记忆不是聊天全文库。它只保存经过确认或可追溯的结构化信息，具备来源、时间、分类、可纠正、可失效、可检索的边界。删除会话不等于删除长期记忆；删除长期记忆必须由用户显式操作。

## 2. 记忆类型

| 类别 | 内容 | 默认可信度 |
|---|---|---|
| 用户偏好 | 饮食偏好、运动偏好、记录习惯、目标偏好 | 用户明确提供 → FACT；AI 观察 → INFERRED，需确认后升级 |
| 训练记忆 | 长期训练安排、动作偏好、已确认的调整、用户反馈 | 用户确认/正式记录 → FACT；AI 总结 → INFERRED |
| 饮食记忆 | 常吃食物、食物替代偏好、用户纠正过的匹配结果 | 用户行为/纠正 → FACT；AI 观察 → INFERRED |
| 目标记忆 | 当前减脂目标、阶段目标、已完成目标、目标变化 | 正式业务数据 → FACT |
| 重要事件 | 计划变更、目标变更、阶段性进展、用户要求长期保存的偏好 | FACT，需来源 |
| AI 推断 | 用户可能偏好某类训练、某阶段状态可能偏低 | INFERRED，禁止自动升级为 FACT |

不保存：

- 全部聊天原文。
- API Key、日志、临时工具结果。
- 未确认的模型猜测。
- 与当前任务无关的个人敏感信息。

## 3. 数据模型语义（阶段 I 实施）

每条记忆至少表达：

- `memoryId`
- `category`：偏好 / 训练 / 饮食 / 目标 / 事件 / 推断
- `content`：结构化内容，不是大段聊天
- `truthType`：`USER_FACT` / `CONFIRMED` / `INFERRED`
- `source`：用户输入 / 正式业务记录 / 用户确认 / AI 推断
- `sourceRef`：来源记录 id 或会话消息 id（可空）
- `createdAt` / `updatedAt`
- `expiresAt`：可空；到期自动失效
- `status`：ACTIVE / INVALIDATED / EXPIRED
- `confidence`：仅 INFERRED 有效，不能当 FACT 概率使用

存储位置：AI 库 `qingji_ai.db` 的用户记忆表；个人食物纠正的主库用户侧表与记忆表通过来源标识关联，不复制公共食物数据。

## 4. 写入规则

| 来源 | 是否可直接写入 | 规则 |
|---|---|---|
| 用户明确说“记住…” | 是 | 标 USER_FACT，可查看/删除 |
| 用户纠正 AI 结果 | 是 | 标 CONFIRMED，记录原识别与纠正结果 |
| 正式业务记录派生 | 是（有限） | 标 FACT，sourceRef 指向正式记录；记录变化时可失效 |
| AI 观察用户习惯 | 否 | 标 INFERRED，需用户确认后才能升级 |
| 聊天全文 | 否 | 不作为长期记忆 |
| 工具临时结果 | 否 | 任务结束即失效 |

## 5. 检索与注入

- 按任务类别检索：训练问题只读训练/目标相关记忆；饮食问题只读饮食/偏好相关记忆；身体分析只读目标/趋势相关记忆。
- 默认只注入少量高相关记忆，受 Token 预算约束。
- 注入内容带 `truthType`，让模型知道是事实还是推断。
- 不注入已失效、过期、低相关的记忆。
- 同一记忆不重复注入同一任务。

## 6. 用户控制

必须提供：

- 查看记忆列表。
- 按类别筛选。
- 纠正错误记忆。
- 标记失效/删除。
- 设置“不再记住此类内容”。
- 区分“删除会话”和“删除记忆”。

删除会话：

- 删除该会话消息、工具历史、会话内临时状态。
- **不自动删除长期记忆**。
- 若用户选择“同时删除相关记忆”，需二次确认并列出将删除项。

删除记忆：

- 用户显式操作。
- 删除后不能影响正式业务记录。
- 来源为正式业务数据的记忆被删后，下次分析可重新派生，但需用户知晓。

## 7. 失效与过期

- 目标变化：旧目标记忆标 INVALIDATED，不删除历史。
- 计划变更：旧计划摘要记忆失效，保留事件记忆。
- 食物纠正变化：新纠正覆盖旧纠正，旧记录失效。
- `expiresAt` 到期：自动 EXPIRED，不参与注入。
- 备份恢复后发现记忆 sourceRef 指向不存在记录：标 INVALIDATED。

## 9. 测试要求

- 用户明确记忆写入与读取。
- AI 猜测不自动升级为 FACT。
- 用户纠正记忆。
- 分类检索不串类。
- 过期/失效不注入。
- 删除会话不删除长期记忆。
- 用户显式删除记忆后不影响业务记录。
- 备份恢复后 sourceRef 失效处理。
- 饮食/训练/目标只读取相关记忆。
